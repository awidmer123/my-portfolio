# 📷 My Photography Portfolio

A personal photography portfolio built with Next.js and Cloudinary.
Created and maintained by me.

## About
This portfolio is my little corner of the internet
to share what I capture.. I am an absolutely non-professional. Neither in web development nor in photography.

## Features
- 📁 Albums — photos organised by trip or project
- 🖼️ Clean gallery layout
- ⬇️ Download photos
- 🌍 Hosted live on Vercel

## Live Site
👉 [my-portfolio-tau-lake-39.vercel.app](https://my-portfolio-tau-lake-39.vercel.app)

## Tech Stack
- [Next.js](https://nextjs.org/): React framework
- [Cloudinary](https://cloudinary.com/): photo storage & delivery
- [Tailwind CSS](https://tailwindcss.com/): styling
- [Vercel](https://vercel.com/): hosting

## Running locally

```bash
npm install
npm run dev
```
